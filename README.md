# Email Signature Generator

A professional email signature generator that helps create eye-catching email signatures with customizable templates.

## Features

- **Live Preview**: See your signature in HTML and PNG formats in real-time
- **Customizable Templates**: Choose from three distinct themes:
  - Minimal (Inter font)
  - Tech (JetBrains Mono)
  - Creative (Space Grotesk)
- **Mobile-Ready**: Ensures crisp images and readable text on any device
- **Export Options**: 
  - Copy HTML version
  - Download as PNG
- **Profile Photo**: Upload and include your professional photo
- **Social Links**: Add LinkedIn, Twitter, and website links
- **Responsive Design**: Works seamlessly across all devices

## Tech Stack

- React
- Tailwind CSS
- Framer Motion
- HTML2Canvas

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/abhinavv-soni/signature_generator.git
```

2. Install dependencies:
```bash
cd signature_generator/frontend
npm install
```

3. Start the development server:
```bash
npm start
```

## Usage

1. Choose a template style (Minimal, Tech, or Creative)
2. Fill in your details (name, title, company, etc.)
3. Upload a profile photo (optional)
4. Add your social media links
5. Preview your signature in real-time
6. Export as HTML or PNG
